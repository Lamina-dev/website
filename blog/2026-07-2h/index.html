#完成事项

  • LMCAS
    • 新增 LSR 表达式与标准库适配层，接入数学函数、复数、随机数、统计、线性代数、单位与常量等接口
    • 暴露 LSR 表达式门面的集合结果、根式、方程组求解、复数部件、特征值分解与 SVD 等能力
    • 增加 LSR 等价性配置，并支持多项式、三角、指数-对数、复数幂等表达式等价性证明
    • 增强 LSR 诊断消费，覆盖空输入、奇异矩阵、定义域错误、非有限数值、非法区间、零方差、矩形矩阵等边界情况
    • 增加对 LSR 标准常量、虚数单位别名与抽象单位维度的上层暴露
    • 修复 Linux 数值构建、BigInt 转换歧义、整数根区间校验、空变量集合求解等问题
    • 补充 LSR 包消费测试与 test_lsr_expr 覆盖，验证错误状态、参数边界、表格输出清理和跨库 ABI 行为
  • LMMC
    • 新增 LSR 标准库适配层，并将数学、复数、随机数、统计、线性代数、单位与常量接口纳入统一 C API
    • 暴露 LSR 状态码诊断名称，新增空输入、奇异矩阵等错误状态
    • 支持 LSR 线性代数表格结果，包括 eig、SVD 等结果导出
    • 新增统计协方差、标准常量、单位标准库与抽象单位维度相关接口
    • 修正数学 log 签名、常量单位运行期、随机数与复数适配参数校验、非有限输入/输出处理、定义域错误报告与表格失败清理
    • 补充 test_lsr_stdlib 覆盖，集中测试诊断、边界参数、非有限数值、单位解析、随机分布、统计空输入和线性代数异常路径
  • LAMMP
    • 新增任意长度近似立方根函数，并补充立方根相关测试
    • 重新实现平方根计算，修复平方根、立方根在边界输入下的若干错误
    • 新增 lmmp_fill_ 填充函数与 ASSUME 宏，调整带副作用断言的使用方式
    • 新增并接入 lmmp_mullo_basecase_ 汇编函数，完善低半乘法路径
    • 优化 bninv 中 na == 1 的特殊情况，修复缓冲区大小高估等问题
    • 调整 lmmpn、numth、临时分配、长整型辅助等接口注释，并清理错误注释与 FIXME
    • 补充 test_cbrt、test_sqrt、test_perfsqr 等测试，修复部分测试错误
